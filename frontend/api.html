How a conversion worksComment se déroule une conversion

Conversion does not happen inside a single request. You upload the file, the server answers immediately with a job id, and you poll that job until it is done. Large models would otherwise hit an HTTP timeout.La conversion ne tient pas dans une seule requête. Vous envoyez le fichier, le serveur répond aussitôt avec un identifiant de job, puis vous interrogez ce job jusqu'à la fin. Sinon, les gros modèles dépasseraient le délai HTTP. 

curl -F "file=@model.ifc" https://iconvex-backend.onrender.com/api/convert
# {"jobId":"7c1f…","status":"converting"}

curl https://iconvex-backend.onrender.com/api/jobs/7c1f…
# {"status":"complete","downloadUrl":"/api/jobs/7c1f…/download", …}

curl -OJ https://iconvex-backend.onrender.com/api/jobs/7c1f…/download
# model.xkt

EndpointsEndpoints

POST /api/convert

Uploads one .ifc file as multipart/form-data under the field name file, and queues it. Responds 202 before the conversion has started.Envoie un fichier .ifc en multipart/form-data sous le champ file, et le met en file. Répond 202 avant même que la conversion ne démarre. 

{ "jobId": "7c1f8e2a-…", "status": "converting" }

Errors: 400 if no file was sent or the extension is not .ifc; 413 if the file is over the size limit.Erreurs : 400 si aucun fichier n'est envoyé ou si l'extension n'est pas .ifc ; 413 si le fichier dépasse la taille limite.

GET /api/jobs/:jobId

Reports where the job stands. status is one of queued, converting, complete or error. downloadUrl is null until the job completes.Indique où en est le job. status vaut queued, converting, complete ou error. downloadUrl reste null jusqu'à la fin. 

{
  "id": "7c1f8e2a-…",
  "status": "complete",
  "originalName": "model.ifc",
  "error": null,
  "downloadUrl": "/api/jobs/7c1f8e2a-…/download"
}

Errors: 404 when the job is unknown — see the note on restarts below.Erreurs : 404 si le job est inconnu — voir la note sur les redémarrages plus bas.

GET /api/jobs/:jobId/download

Returns the .xkt as an attachment, named after the file you uploaded.Renvoie le .xkt en pièce jointe, nommé d'après le fichier envoyé.

Errors: 404 if the job is unknown; 409 if it has not finished yet.Erreurs : 404 si le job est inconnu ; 409 s'il n'est pas encore terminé.

GET /api/health

Liveness check. Useful to wake the server before uploading — see below.Test de vie. Utile pour réveiller le serveur avant un envoi — voir plus bas. 

{ "ok": true, "service": "iconvex-backend" }

From JavaScriptDepuis JavaScript 

const body = new FormData();
body.append('file', ifcFile);

const { jobId } = await fetch(`${BASE}/api/convert`, { method: 'POST', body })
  .then((r) => r.json());

let job;
do {
  await new Promise((r) => setTimeout(r, 1500));
  job = await fetch(`${BASE}/api/jobs/${jobId}`).then((r) => r.json());
} while (job.status === 'queued' || job.status === 'converting');

if (job.status === 'complete') window.location = `${BASE}${job.downloadUrl}`;

Limits worth knowing before you build on thisLimites à connaître avant de construire dessus

  • Calling from a browser on another domain will be blocked. CORS only allows the IConveX site itself. Server-side calls — curl, Node, any backend — are not subject to CORS and work from anywhere.Un appel depuis un navigateur sur un autre domaine sera bloqué. CORS n'autorise que le site IConveX lui-même. Les appels côté serveur — curl, Node, n'importe quel backend — ne sont pas soumis à CORS et fonctionnent depuis partout.
  • The first call after a quiet spell can take 50 seconds or more. The server runs on a free instance that sleeps when idle. Call /api/health first to wake it.Le premier appel après une période d'inactivité peut prendre 50 secondes ou plus. Le serveur tourne sur une instance gratuite qui s'endort. Appelez /api/health d'abord pour le réveiller.
  • Conversion is not fast. The instance has a fraction of a CPU; a few megabytes of IFC can take minutes. Poll patiently rather than timing out early.La conversion n'est pas rapide. L'instance dispose d'une fraction de CPU ; quelques mégaoctets d'IFC peuvent prendre plusieurs minutes. Interrogez patiemment plutôt que d'abandonner trop tôt.
  • Jobs do not survive a restart. The queue is held in memory, so a redeploy or a crash turns a job id into a 404. Treat that as "start again", not as a transient error.Les jobs ne survivent pas à un redémarrage. La file est en mémoire : un redéploiement ou un plantage transforme un identifiant en 404. Traitez ça comme « recommencer », pas comme une erreur passagère.
  • Only .ifc files are accepted, and finished files are deleted automatically about an hour after conversion. Download promptly.Seuls les fichiers .ifc sont acceptés, et les fichiers produits sont supprimés automatiquement environ une heure après la conversion. Téléchargez sans tarder.
  • There is no authentication and no rate limiting. This is a free, shared, best-effort service — do not build anything you depend on without running your own instance.Il n'y a ni authentification ni limitation de débit. C'est un service gratuit, partagé et sans garantie — ne construisez rien de critique dessus sans héberger votre propre instance.
